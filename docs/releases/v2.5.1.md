# Go v2.5.1

v2.5.1 fixes the PostgreSQL upgrade path for existing v2.5.0 bot databases.

## Fixed

- Adds a dedicated schema migration marker for `chain_transfer_states`.
- Existing databases now run the idempotent lifecycle-table migration instead of returning early at the previous schema marker.
- Pending watcher deliveries that previously failed with `relation "chain_transfer_states" does not exist` can be retried and acknowledged after upgrade.
- Adds a PostgreSQL integration test that starts from the prior v2.5.0 migration marker and verifies both upgrade and idempotent reopen behavior.

Kafka, Pending/Confirmed deduplication, and Tronscan failover behavior are otherwise unchanged from v2.5.0.
