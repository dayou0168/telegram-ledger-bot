# v2.5.2

地址监听的 USDT 与 TRX 提醒现在具有独立开关和独立最低金额。

- 后台地址监听新增 `TRX` 开关和 `TRX 最小提醒`。
- 私聊地址设置新增 TRX 开关与 TRX 最小金额。
- `USDT 最小提醒` 仅过滤 USDT，`TRX 最小提醒` 仅过滤 TRX。
- 拒绝零值、负值和无效金额事件。
- 升级迁移会关闭历史地址中从未显式配置过的 TRX 提醒，避免微额 TRX 误报；需要 TRX 时可升级后重新开启。
- watcher 订阅协议和数据库增加 `min_trx_amount` / `min_notify_trx_amount` 字段。

机器人和 `ledger-chain-watcher` 必须同时升级到 v2.5.2。
